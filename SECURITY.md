# Security policy

Motefield runs entirely in the browser. It has no server-side component, stores nothing, and sends nothing except the two model downloads from Hugging Face (see README). Still, bugs in file parsing, worker messaging or the export pipeline could have security implications.

## Reporting

Please do not open public issues for security problems. Report them privately through the repository's security advisory feature ("Report a vulnerability" on GitHub) once the repository is public, or to the maintainers' contact listed in the repository profile. Include steps to reproduce and the browser and version you used.

You will get an acknowledgement within a week. Fixes are published as ordinary releases with a note in the changelog.

## Supported versions

Only the latest release on the main branch receives fixes.
